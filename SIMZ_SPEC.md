# SIMZ — Simulated Company Specification

**SIMZ is a fully simulated company.** It is operated by SQUIRL OS Technologies as a workload and demonstration tenant. It is not a real business, has no real customers or employees, carries no real financial records, and contains no personal or health data. Every surface that displays SIMZ carries the simulated-company disclosure.

## Purpose

1. **Second independent workload generator** — alongside the existing simulation corpus, SIMZ drives concurrent synthetic M365 telemetry at Microsoft healing playbooks through its own SQUIRL OS instance. Two independent tenants = genuine multi-tenant concurrent load for the H-Line.
2. **Hosted-company demonstration** — SIMZ is hosted on the SQUIRL OS domain as the second company in the hosted model, showing the platform taking on another simulated tenant end-to-end: onboarding, monitoring, healing, books, taxes.
3. **Buyer-interest showcase** — a second fully-operated tenant proves the multi-tenant model without ever touching real customer data.

## Profile (all values synthetic)

- Fictional SMB: 40 simulated employees, one simulated M365-style tenant.
- Simulated operations: service tickets, mailbox/license/SharePoint/AD-style telemetry events, endpoint inventories — all **synthetically generated by the workload generator**.
- Simulated books: invoices, expenses, payroll runs, quarterly tax filings — all simulated values, clearly marked.
- Simulated incidents feed the healing pipeline (anomaly detection, playbook matching, healing events, pattern learning).

## Isolation (hard rules)

1. **Synthetic telemetry only.** SIMZ never calls the live M365 tenant. All telemetry is generated under our control. (Substrate isolation: the live tenant feeds the Lindy run and must stay untouched.)
2. **Identity isolation.** Owner identity hardcoded; no dynamic profile pulls; no cross-tenant drift.
3. **Separate ledger.** SIMZ receipts append to the H-Line ledger, never the Lindy ledger.
4. **Doctrine.** Same rules as the existing simulated corpus: fair game on every public surface **with** the simulated-company disclosure; no PHI; no real credentials; prototype disclaimer everywhere.

## Data model (SIMZ app)

SQUIRL OS 15-entity template plus sim-corpus entities (all values synthetic, marked simulated): SimEmployee, SimInvoice, SimExpense, SimPayrollRun, SimTaxFiling, SimTicket, SimTelemetryEvent, SimTenantConfig.
